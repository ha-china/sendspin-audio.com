许可与商标

Sendspin 是免费且开放的，并将永远如此：任何人都可以实现该协议，无需支付任何版税或专利费。它由 Open Home Foundation（一家瑞士非营利组织）管理，因此不会被任何单一公司收购、封闭或商业化。本页仅为条款摘要；所链接的文档具有权威性。

#协议规范

Sendspin 规范 以 Community Specification License 1.0 发布。该许可包含每位贡献者授予的免版税专利许可，适用于规范范围内的实现，因此您可以将 Sendspin 集成到您的产品中，而无需向任何人付费或请求许可。

对规范的贡献依据 贡献者许可协议 接受。规范按“原样”提供，不附带任何保证；完整的免责声明请参见许可协议。

#SDK 与参考实现

官方 SDK 和参考实现均为开源。每个仓库在其自身的 LICENSE 文件中声明其许可证；参考客户端和参考服务器采用 Apache 2.0 许可证。使用 SDK 不会改变本页的条款：规范许可涵盖协议本身，下述商标规则涵盖名称和徽标。

#Sendspin 名称与徽标

Sendspin 名称和 Sendspin 徽标是 Open Home Foundation 的商标。规范许可不授予任何商标权利：实现该协议并不意味着您有权在产品上使用该名称或徽标。

未经许可，您可以：

  • 以纯文本形式客观陈述某产品实现了 Sendspin 协议或与 Sendspin 兼容，且不得暗示获得背书或认证；
  • 在文档、源代码和讨论中按名称提及该协议；
  • 使用规范定义的标识符，例如 mDNS 服务类型 _sendspin._tcp 和 _sendspin-server._tcp；
  • 在项目名称中的描述性位置使用该名称，例如“Foo for Sendspin”或“Sendspin-compatible Foo”。

以下情况需要获得许可：

  • 在出售的产品上，或在此类产品的营销中，使用 Sendspin 名称或徽标；
  • 将 Sendspin 用作项目自身的名称，例如“Sendspin Player”或“Sendspin for Windows”，因为这会将其呈现为该协议自身的软件，无论该项目是否开源。

许可通过正在筹备中的 Sendspin 合作伙伴计划授予。制造商可以让其实现接受测试和认证，随后即可使用认证标志、徽标以及本网站上的列表。请参见合作伙伴页面和完整的商标政策。

#有疑问？

不确定您的使用是否在涵盖范围内？请发送电子邮件至 sendspin@openhomefoundation.org。
