大多数系统止步于声音。

Sendspin 让封面、控制与节拍随音频同行。音箱、平板、灯，如同一个房间的整体。它是一个开放标准，任何设备都能加入——包括你已经拥有的。

{% include "icons/speaker.svg" %}

声音

高质量音频，全屋音箱同步播放。到高保真音响是无损，到厨房智能音箱是高能效编码，全部锁定在同一个节拍。

{% include "icons/monitor.svg" %}

屏幕

每台平板与显示屏展示封面与播放信息。走廊的壁挂面板变成“正在播放”屏，再也不必摸出手机。

{% include "icons/remote.svg" %}

控制

任何屏幕都可以是遥控器。在家的任何位置切歌、暂停、调音量。手机在兜里还是平板在墙上，同一套控制。

{% include "icons/light.svg" %}

灯光

LED 灯带与智能灯泡取色自专辑封面，随音乐律动。低音给落地灯，中音给电视后面那条灯带。

{% include "icons/turntable.svg" %}

音源输入

声音既能输出也能采集。把唱机、CD 机或任何线路输出接进 Sendspin 设备，它听到的声音就会在全屋每只音箱上响起。

什么设备都能当音箱。

Sendspin 是一个标准，任何厂商都能为它造音箱——你也可以。无论用哪个设备，播放的都是同一时刻的同一首歌。你需要两样东西：一只音箱，和一个音乐源。

按你的方式。

Sendspin 不把你锁进某个品牌或云。它是开放标准，跑在你自己的网络上，由非营利组织管理。你的音乐数据从不离开家门。

{% include "icons/branches.svg" %}

没人替你做决定。

下一台添加什么音箱、用什么应用、硬件能用多久，都由你说了算。规范是公开的，没有哪家公司能替你做这些选择。

{% include "icons/handoff.svg" %}

留下你的旧设备。

用了多年的功放、架上的音箱、阁楼里的高保真设备。一部旧手机或一块十美金开发板，就能把它们都接进来。配合 Music Assistant，已有的 AirPlay 音箱也能加入群组。

{% include "icons/lock.svg" %}

没有云账号。

一切都在家庭网络里。你从不注册账号，一次授权即可让设备间的音频保持加密。你听什么只留在家里，不会流向大公司。
